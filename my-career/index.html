求人データはこのページには公開されません

初回設定：トークンの作り方
  1. GitHubのFine-grained token作成画面を開く。
  2. Repository accessは Only select repositories で my-career-ranking のみ選択。
  3. Repository permissionsは、閲覧だけなら Contents: Read-only、アプリから編集・追加して保存するなら Contents: Read and write に設定。ほかの権限は不要です。
  4. 生成されたトークンをコピーし、上の欄に貼り付ける。トークンをチャットや公開ページに投稿しないでください。

このページに求人データ・トークンは埋め込まれていません。入力したトークンはGitHub APIとの通信にのみ使用します。編集時は非公開リポジトリへの書き込みに使用します。トークンはこのサイト側のサーバーには送信せず、求人データはブラウザー保存しません。書き込み権限付きトークンの取扱いには十分注意してください。
