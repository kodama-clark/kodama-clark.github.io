初回設定：トークンの作り方
  1. GitHubのFine-grained token作成画面を開く。
  2. Repository accessは Only select repositories で my-career-ranking のみ選択。
  3. Repository permissionsは Contents: Read-only のみを設定。必要に応じて有効期限を選ぶ。
  4. 生成されたトークンをコピーし、上の欄に貼り付ける。トークンをチャットや公開ページに投稿しないでください。

このページに求人データ・トークンは埋め込まれていません。入力したトークンはGitHub APIへの読み取りにのみ使用し、当サイト運営者のサーバーに送信しません。求人データをブラウザー保存しません。
